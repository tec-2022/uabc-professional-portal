# Política de datos de demostración

Este repositorio es una **base profesional reutilizable**. El contenido incluido sirve para demostrar componentes, densidad realista de información y flujos del portal.

## Qué significa "datos de ejemplo"

- Los nombres, publicaciones, proyectos, eventos, cursos, imágenes, enlaces, DOI, textos y demás registros pueden ser demostrativos o incompletos.
- La presencia de una institución, persona o identificador en la demo no convierte esta plantilla en su sitio oficial.
- Los placeholders como `#`, DOI de ejemplo o imágenes remotas se conservan deliberadamente para enseñar los estados que la interfaz soporta.

## Criterio de calidad

Aunque los datos sean de ejemplo, la demo debe verse como un producto terminado:

- tipografía, espaciado y responsive consistentes;
- formularios y estados vacíos cuidados;
- contenido bilingüe soportado;
- accesibilidad y navegación por teclado;
- SEO técnico, PWA y seguridad configurados;
- Admin Studio funcional en modo preparación;
- build reproducible y Quality Gate en CI.

## Antes de usar la base en producción real

Sustituye los datos demo, revisa textos legales, define un dominio propio, verifica derechos de imágenes/archivos y conecta autenticación/backend únicamente si se requiere edición remota.
