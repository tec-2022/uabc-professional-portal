# Academic Professional Portal

[Español](README.md) · **English** · [Live demo](https://prueba-pi-eight.vercel.app) · [Sponsor](https://github.com/sponsors/tec-2022)

[![Academic Professional Portal demo](docs/media/demo.gif)](docs/media/demo.mp4)

A reusable academic and professional portal foundation with dashboard navigation, offline support, human-friendly configuration and automated quality checks.

## Quick start

```bash
npm ci
npm run build
npm run serve
```

Run `npm run check` for the build and audit, or `npm test` for Playwright coverage. Configuration lives in `portal.config.json`; see the [Spanish documentation](README.md) for architecture and administration details.

## Contributing and security

Read [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md). Never add real institutional credentials or personal student records to sample content.
